# Jogo de Xadrez em C#

## 📖 Descrição
Este projeto é uma implementação de um jogo de xadrez em C#, desenvolvido exclusivamente com **programação orientada a objetos (POO)** e executado no **terminal**.  
O objetivo é praticar conceitos de classes, herança, polimorfismo e encapsulamento, além de aplicar regras clássicas do xadrez.

## 🎯 Funcionalidades
- Representação completa do tabuleiro de xadrez em texto.
- Movimentação das peças conforme as regras oficiais.
- Validação de movimentos (incluindo xeque e xeque-mate).
- Alternância de turnos entre jogadores.
- Exibição do estado atual do jogo no terminal.

## 🛠️ Tecnologias utilizadas
- Linguagem: **C#**
- Paradigma: **Programação Orientada a Objetos**
- Ambiente: **.NET SDK** (versão recomendada: 6.0 ou superior)
